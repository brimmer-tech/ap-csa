A record company uses the following variables to maintain information about each song in the company’s catalog.

  • downloads is an int variable that represents the number of times a song was downloaded. Assume the value of this variable is positive.
  • songInfo is a String variable that contains information about the song. The string consists of the artist name, followed by a hyphen ("-"), followed by the album title, followed by another hyphen, followed by the song title. Assume that no other hyphens appear in the string.
Tips before you start
  • You’re writing a code segment, not a whole method or class. The variables above already exist and already have values.
  • Read the rules, then check them against every row of the table. The table shows the edge cases.
  • Stick to tools from the Java Quick Reference: length(), substring, indexOf, equals, plus the % and / operators for digits.

Example

How to work an FRQ, step by step

Follow one student through a made-up practice question. It isn’t one of your questions, so nothing here gives away an answer. Watch the steps, then use the same steps on 1a.

The practice question: A code segment, which you will write, should print the number of places in word where a character is immediately followed by the same character.

1Read the setup first

Before the task, list what already exists and what you’re promised about it. The student wrote:

  • word is a String.
  • It’s non-null, so calling word.length() is safe.
  • Nothing says it has letters in it, so it could be "".

2Say the task in your own words

The student rewrote it as: “Count the spots where a letter has the same letter right after it. Print that count once.”

Then they answered two questions: What gets printed? A number. How many times? Once.

3Study the table, row by row

Every row is there for a reason. The student added a column saying what each row tests.

Value of wordPrinted OutputWhat this row tests
"book"1The basic case: one pair, oo.
"aaa"2Pairs can overlap. Positions 0–1 and 1–2 both count.
"bookkeeper"3More than one pair: oo, kk, ee.
"cat"0No pairs at all.
"a"0One letter has nothing after it.
""0An empty string must not crash.

4Plan in plain English before any code

  1. Start a count at 0.
  2. Look at each character that has a character after it.
  3. If the two match, add 1 to the count.
  4. When the loop is done, print the count.

If you can’t write this plan, that’s the moment to open hint 1. Read it, close it in your head, and try the plan again before you open hint 2.

5Write a first draft

The student turned each line of the plan into code:

int count = 0;
for (int i = 0; i < word.length(); i++)
{
    String here = word.substring(i, i + 1);
    String next = word.substring(i + 1, i + 2);
    if (here.equals(next))
    {
        count++;
    }
}
System.out.println(count);

It looks finished. Most students stop here. This student didn’t.

6Trace it with a row from the table

The student traced "book" by hand, one row per trip through the loop:

iherenextMatch?count
0"b""o"no0
1"o""o"yes1
2"o""k"no1
3"k"substring(4, 5)Error: index 5 is past the end

The trace caught the bug. The last character has nothing after it, so the loop has to stop one step earlier.

7Fix it and trace again

for (int i = 0; i < word.length() - 1; i++)

Now "book" stops after i = 2 and prints 1. The student also checked the edge rows quickly:

  • "a": the loop needs 0 < 0, which is false, so it never runs. Prints 0.
  • "": the loop needs 0 < -1, which is false. No crash. Prints 0.

8Tick “Check yourself” only after tracing

Each box means “I traced this row and my code printed exactly this.” A box ticked without tracing is how the bug in step 5 would have reached the exam.

The process, in short: read the setup, restate the task, study the table, plan in words, draft, trace, fix, trace again.

1a

A code segment, which you will write, should print output according to the following rules.

  • If the length of text is greater than colWidth, then the value of text will be printed.
  • Otherwise, the printed output will consist of colWidth characters contained between two "|" characters. The text between the "|" characters will consist of a sequence of periods ("."), followed by the value of text, followed by another sequence of periods.

    The printed output will have an equal number of periods on each side of text, if possible. If this is not possible, then there will be one fewer period on the left side of text than on the right side of text.

The intended behavior is illustrated in the following table.

Value of colWidthValue of textPrinted Output
5"ab"|.ab..|
5"abc"|.abc.|
10"ab"|....ab....|
10"abc"|...abc....|
10"abcdefghij"|abcdefghij|
10"abcdefghijklmnopqrstuv"abcdefghijklmnopqrstuv

Write a code segment to print the intended output. Your implementation must meet all specifications and conform to the examples shown in the table.

Check yourself

Trace your code by hand for each row. Tick it only if your code prints exactly what the table shows.

      2a

      A code segment, which you will write, should determine whether the ones digit of the number stored in downloads appears exactly one other time in the number. If so, the code segment should print "exactly once"; otherwise, it should print "not exactly once".

      For example, if downloads has a value of 1734567, then the segment should print "exactly once" because the ones digit, which is 7, appears one other time.

      As another example, if downloads has a value of 325322, then the segment should print "not exactly once" because the ones digit, which is 2, appears two other times.

      Write a code segment to print the intended output. Your implementation must conform to the examples.

      Check yourself

      Trace your code by hand for each value. The last two aren’t in the question, but they test the edges.

        2b

        A code segment, which you will write, should process the string songInfo and print the song title and artist name separated by the string (" by ").

        For example, if songInfo is "Carrie Ferriero-Greatest Hits-Tell Me Why", then the code segment should print "Tell Me Why by Carrie Ferriero".

        As another example, if songInfo is "Aniita-Mixtape 2-How Much More", then the code segment should print "How Much More by Aniita".

        Write a code segment to print the intended output. Your implementation must conform to the examples.

        Check yourself

        Trace your code by hand for each value. The last one isn’t in the question, but it tests the shortest possible parts.
