Program structure, output, and comments

A Java program is a class with a main method. The compiler checks every line before anything runs: a syntax error stops compilation, a logic error runs but gives a wrong answer, and a run-time error (like dividing an int by zero) crashes while running.

  • System.out.print(x) prints and stays on the line; System.out.println(x) prints and moves down; System.out.println() prints a blank line.
  • Comments: // one line, /* many lines */, and /** Javadoc */ where the exam states a precondition (must be true before a method runs) and a postcondition (guaranteed after).
  • Escapes inside strings: \n new line, \" quote, \\ backslash, \t tab.

\" becomes a real quote mark and \n breaks the line inside a single println.

  • = is assignment, not equality. The right side is computed first, then stored. x = x + 1; is normal.

Expressions and operators

Int divided by int gives an int: the remainder is thrown away. % gives that remainder.

  • Precedence: parentheses, then * / % left to right, then + - left to right.
  • Integer division by zero throws ArithmeticException; double division by zero does not.
  • Shortcuts: x += 3, x -= 3, x *= 3, x /= 3, x %= 3, x++, x--. The exam only uses ++/-- as standalone statements.
What is x?
int x = 17 / 5 + 17 % 5;

17 / 5 is 3 (remainder dropped). 17 % 5 is 2. 3 + 2 = 6.

What prints?
System.out.println("Total: " + 2 + 3);

Once a string is on the left, + concatenates. "Total: " + 2 is "Total: 2", then + 3 appends another character.

Total: 23
What is r?
int r = 13 % 4 * 2 / 3 + 1 % 5;

Left to right at the same level: 13 % 4 = 1, 1 * 2 = 2, 2 / 3 = 0. Then 1 % 5 = 1. 0 + 1 = 1. If you got 2, you skipped the integer division in 2 / 3.

Casting, ranges, and overflow

Casting a double to an int truncates (chops the decimal, never rounds).

Study these five, then predict the values of a b c d e (space-separated).
int a = (int) 3.99;
int b = (int) -3.99;
double c = (double) 7 / 2;
double d = (double) (7 / 2);
int e = (int) (3.7 + 0.5);

a = 3 and b = -3: truncation toward zero. c = 3.5: the cast grabs only the 7, so it is 7.0 / 2. d = 3.0: the division finished first. e = 4: the + 0.5 rounding trick.

  • int to double is automatic (widening). double to int needs (int) (narrowing) or it will not compile.
  • Round a positive double: (int) (x + 0.5). Negative: (int) (x - 0.5).
  • Integer.MAX_VALUE is 2,147,483,647; Integer.MIN_VALUE is -2,147,483,648. MAX_VALUE + 1 wraps to MIN_VALUE with no error: that is overflow.
  • Doubles are not exact: 0.1 + 0.2 is not exactly 0.3, so avoid == with doubles.
What is (int) (10 / 4.0) + 10 / 4?
int v = (int) (10 / 4.0) + 10 / 4;

10 / 4.0 = 2.5, cast to 2. 10 / 4 = 2. Sum 4.

Objects, constructors, and calling methods

A class is the blueprint; new builds an object and the variable stores a reference to it. A constructor has the class name and no return type.

// The exam hands you an API like this; you never see the code inside.
public class Account
{
    public Account(String owner, double balance)
    public void deposit(double amount)        // void: a statement
    public double getBalance()                // non-void: use the value
}

Account a = new Account("Lee", 100);   // 100 widens to 100.0
a.deposit(50);                             // instance method on a
double b = a.getBalance();                 // 150.0
int big = Math.max(3, 9);                  // class (static) method
  • Signature = name + parameter list. Parameters are in the header; arguments are the values you pass. Count, order, and types must match.
  • void methods return nothing: double x = a.deposit(5); will not compile.
  • Instance methods need an object (a.getBalance()). Class/static methods use the class name (Math.abs(-2)).
  • Objects copy references: after Account c = a;, both names point at the same account.
  • null means no object. Calling a method on null throws NullPointerException.
  • Overloading: same name, different parameter lists. Math.abs(-3) returns an int; Math.abs(-3.5) returns a double.
Using the Account API above, which line compiles? Type the letter.
A  Account a = new Account(100.0, "Lee");
B  double d = a.deposit(50.0);
C  Account a = new Account("Lee", 100);
D  a.getBalance(25.0);

A has the arguments reversed. B assigns a void. D passes an argument to a method with no parameters. C works because the int 100 widens to a double.

What prints? (space-separated)
Account a = new Account("Lee", 100);

c.deposit(50);

c = a copies the reference, not the object. One account, two names, one deposit.

Substring visualizer

Highlighted cells are included; the dashed cell is to, which is not. The result always has to - from characters.

  • Valid indexes are 0 to length() - 1. substring(a, b) needs 0 ≤ a ≤ b ≤ length() or it throws StringIndexOutOfBoundsException. substring(len, len) is legal and gives "".
  • Immutable: s.substring(1); alone changes nothing. Store it: s = s.substring(1);
  • Compare with equals, never ==, which compares references.
  • compareTo uses character codes, so every uppercase letter comes before every lowercase: "Zebra".compareTo("apple") is negative.
  • One character on the AP subset: s.substring(i, i + 1) (not charAt).

The Math class

All Math methods are static: Math.method(...), no object. pow and sqrt always return a double, even for Math.pow(2, 3) (which is 8.0). Math.random() returns a double from 0.0 up to but never including 1.0.

Random range builder

Reading one on the exam: the number multiplied is how many values are possible, and the number added is the lowest value.

  • int x = Math.pow(2, 3); will not compile. Cast it: (int) Math.pow(2, 3).
  • Distance: Math.sqrt(Math.pow(x2 - x1, 2) + Math.pow(y2 - y1, 2)).
  • Wrapper classes (Integer, Double) are lesson 4.7 in Cortado, not Unit 1.
What are the smallest and largest values n can be? (two numbers, space-separated)
int n = (int) (Math.random() * 5) + 10;

Math.random() * 5 is 0.0 to 4.999…, cast to 0–4, plus 10 gives 10 through 14. Five possible values starting at 10.

FRQ habits

  • Read the method table first. If a method does part of the job, call it.
  • Every String operation that produces a value must be stored or printed.
  • Declare every variable with a type; end every statement with ;.
  • A non-void method must return a value of the right type.
