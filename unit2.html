12 % 2 is 0, so the condition is true and even prints. done is outside the if, so it always prints.

Building blocks of algorithms

Every algorithm is built from three blocks. What changes from one program to the next is which blocks it uses, and in what order.

BlockWhat it doesEveryday exampleIn Java
SequencingSteps run in order, one at a timePut on socks, then shoesstatements one after another
SelectionA true-or-false decision picks the pathIf it is raining, take an umbrellaif, if-else
RepetitionA process repeats until a desired outcome is reachedStir until the sauce thickenswhile, for

The order in which the blocks are combined changes the outcome. The next two tracers use exactly the same statements in a different order.

A recipe says “Stir until the sauce thickens.” Which building block is that? (sequencing, selection, or repetition)

A step that repeats until a desired outcome is reached is repetition. In Java it becomes a loop.

What is x at the end?
int x = 3;
if (x > 2)
{
    x = x - 2;
}
x = x * 4;

x starts at 3. The condition 3 > 2 is true, so x becomes 1. Then x is multiplied by 4: 4.

Same statements, different order. What is x now?
int x = 3;
x = x * 4;
if (x > 2)
{
    x = x - 2;
}

x becomes 12 first. Then 12 > 2 is true, so x becomes 10. The order of the building blocks changes the outcome.

Boolean expressions

A Boolean expression evaluates to true or false. Relational operators build one from two values.

OperatorMeaningExample when x is 7Result
==equal tox == 7true
!=not equal tox != 7false
< >less than, greater thanx > 5true
<= >=at most, at leastx <= 6false
% with ==divisibility testx % 2 == 0false (7 is odd)
  • = stores a value. == compares two values. For an int, if (x = 5) does not even compile.
  • == and != work on any type. With primitives they compare the actual values; with objects they compare references (see the Equivalent expressions section). <, >, <=, >= work only on numbers.
  • A Boolean expression can be stored in a variable: boolean isEven = (n % 2 == 0);
  • Avoid == on computed doubles. Computers cannot store every decimal exactly, so 0.1 + 0.2 == 0.3 is false. Use ints when you need an exact comparison.

What prints?
System.out.println(0.1 + 0.2 == 0.3);

The computer stores 0.1 + 0.2 as a value very slightly different from 0.3 (round-off error), so == reports false. Avoid == with computed doubles.

What prints?
int n = 1237;
System.out.println(n % 10 == 7);

1237 % 10 is 7 (the last digit), so the comparison is true.

if statements and nested if statements

A selection statement changes the sequential flow of a program: it runs different code depending on a Boolean expression.

One-way and two-way selection

  • A one-way selection (if) runs its body only when the condition is true.
  • A two-way selection (if-else) runs exactly one of its two bodies.
int score = 72;
if (score >= 60)
{
    System.out.println("pass");
}
else
{
    System.out.println("retry");
}
  • Use braces every time. Without them, only the single next statement belongs to the if:
int x = 8;
if (x > 5)
    System.out.println("big");
    System.out.println("always");   // not part of the if
  • A semicolon right after the condition, as in if (x > 3);, ends the if with an empty body. Whatever follows always runs.

Multi-way selection

An if / else if / else chain tests conditions from the top. No more than one body runs: the first one whose condition is true. If none is true, a trailing else runs. Because the first true condition wins, the order of the tests matters.

Separate if statementsif / else if chain
Every condition is testedTesting stops at the first true condition
Zero, one, or several bodies can runAt most one body runs

Change the score and watch which branch runs. Conditions after the first true one are never tested.


    

  

  
Nested if statements

  
An if can sit inside another if or else. The inner condition is evaluated only when the outer condition is true. When braces are missing, an else pairs with the nearest unmatched if, no matter how the code is indented.

  

  
What prints?


int n = 15;
String r = "";
if (n % 3 == 0)
{
    r += "Fizz";
}
if (n % 5 == 0)
{
    r += "Buzz";
}
System.out.println(r);

  

  
These are two separate if statements, so both conditions are checked. 15 is divisible by 3 and by 5, so both bodies run.



  

  
Now the second test is an else if. What prints?


int n = 15;
String r = "";
if (n % 3 == 0)
{
    r += "Fizz";
}
else if (n % 5 == 0)
{
    r += "Buzz";
}
System.out.println(r);

  

  
In an if / else-if chain, only the first true branch runs. Once n % 3 == 0 is true, the else-if is skipped.

int x = 1;

{
    System.out.println("big");
}

  

  
The semicolon after the condition is an empty body. The braces that follow are just a plain block that always runs.

    {

a > 0 is true, so the inner if is evaluated. b > 0 is false, so the inner else runs.

An else pairs with the nearest unmatched if, whatever the indentation suggests. Here the else belongs to if (b > 0). Since a > 0 is false, nothing inside is evaluated, and only end prints.








  
Compound Boolean expressions

  
The logical operators ! (not), && (and), and || (or) combine Boolean values.

  

    
aba && ba || b!a

    
truetruetruetruefalse

    
truefalsefalsetruefalse

    
falsetruefalsetruetrue

    
falsefalsefalsefalsetrue

  

  
    
    
  • Precedence: ! first, then &&, then ||. So a || b && c means a || (b && c). Parentheses make your intent clear.
    • 
    
  • Short-circuit evaluation: && skips its right side when the left side is false, and || skips its right side when the left side is true. In that case the right side is never evaluated.
    • 
    
  • Short-circuiting lets you write a guard on the left that protects the right:
    • 
  

  
int x = 10;
int y = 0;
String s = null;
if (y != 0 && x / y > 2)           // never divides by zero
{
    System.out.println("big ratio");
}
if (s != null && s.length() > 0)   // never calls a method on null
{
    System.out.println("has text");
}

  
Try these in the Boolean expression lab: set y to 0 and compare y != 0 && x / y > 2 with x / y > 2 && y != 0.

  

  
What prints?


boolean a = true;
boolean b = false;
boolean c = false;
System.out.println(a || b && c);

  

  
&& is evaluated before ||. So b && c is false, and a || false is true.



  

  
What prints?


int x = 7;
int y = 3;
System.out.println(!(x > 5 && y < 3));

  

  
x > 5 is true and y < 3 is false, so the && is false. The ! flips it to true.



  

  
What prints?


int x = 0;
int count = 0;
if (x != 0 && 10 / x > 1)
{
    count = 1;
}
System.out.println(count);

  

  
x != 0 is false, so the && is already false. Short-circuit evaluation skips the right side, so 10 / x never runs and nothing is thrown.



  

  
The two tests are swapped. What is thrown? (type the exception name)


int x = 0;
if (10 / x > 1 && x != 0)
{
    System.out.println("ok");
}

  

  
Now 10 / x runs first. Dividing an int by the int zero throws an ArithmeticException. Put the guard on the left.








  
Equivalent expressions and comparing objects

  
Two Boolean expressions are equivalent if they evaluate to the same value in all cases. A truth table can prove it.

  
De Morgan’s laws

  

    
ExpressionEquivalent to

    
!(a && b)!a || !b

    
!(a || b)!a && !b

  

  
Negate each part and switch the operator. When the parts are relational, negate the comparison: < becomes >=, > becomes <=, == becomes !=. So !(x < 5) is x >= 5, not x > 5.

Comparing objects

  
    
    
  • Two variables can refer to the same object. == and != compare references: are they the same object?
    • 
    
  • equals compares contents. Use s1.equals(s2) to compare two Strings.
    • 
    
  • You can compare a reference with null using == or != to see whether it refers to an object at all. Calling a method on null throws a NullPointerException.
    • 
    
  • A class can define its own equals, usually comparing the objects’ attributes. (Writing your own equals is outside this course’s exam.)
    • 
  

  
String a = "hi";
String b = a;                  // b refers to the same object as a
String c = new String("hi");   // a different object with the same characters
boolean r1 = (a == b);         // true
boolean r2 = (a == c);         // false
boolean r3 = a.equals(c);      // true

  

  
Which is equivalent to !(a && b)? Type the letter.
A. !a && !b
B. !a || !b
C. a || b
D. a && !b

  

  
De Morgan’s law: negate each part and switch && to ||. A truth table confirms it, and the Equivalence checker above lets you try it.



  

  
Is !(x < 5 || y == 2) equivalent to x >= 5 && y != 2? (yes or no)

  

  
Negate each part (!(x < 5) is x >= 5, and !(y == 2) is y != 2) and switch || to &&.



  

  
What prints?


String a = "hi";
String b = a;
String c = new String("hi");
System.out.println((a == b) + " " + (a == c) + " " + a.equals(c));

  

  
a and b hold the same reference, so a == b is true. c is a different object that happens to hold the same characters, so a == c is false, but a.equals(c) is true.



  

  
What is thrown? (type the exception name)


String s = null;
System.out.println(s.length() > 0 && s != null);

  

  
The reference s is null, so s.length() has no object to run on. The guard s != null must come first.








  
while loops

  
Iteration repeats a segment of code zero or more times, as long as a Boolean expression stays true.

  
int n = 20;                 // initialize
while (n > 1)               // test: checked before every pass, even the first
{
    n = n / 2;              // body: includes an update that moves toward ending
}

  
    
    
  • The condition is evaluated before every pass, including the first. If it is false at the start, the body runs zero times.
    • 
    
  • A loop needs a start, a test, and an update inside the body that eventually makes the test false.
    • 
    
  • An infinite loop happens when the test is always true. An off-by-one error happens when a loop runs one time too many or one time too few.
    • 
  

  

    
SymptomUsual cause

    
Runs foreverThe update is missing, moves the wrong way, or jumps past a test written with !=

    
One pass too many or too few< vs <=, or a start value that is off by one

    
Never runsThe condition is already false before the first pass

  

  
To check a loop, trace the first pass and the last pass. The trace table stepper shows every step.

  

  
What is steps at the end?


int n = 20;
int steps = 0;
while (n > 1)
{
    n = n / 2;
    steps++;
}

  

  
n goes 20, 10, 5, 2, 1. The loop stops when n is 1, after 4 passes.



  

  
What is i at the end?


int i = 10;
while (i < 5)
{
    i++;
}

  

  
The condition 10 < 5 is false the first time, so the body runs zero times. A while loop checks before every pass, including the first.



  

  
Which loop never ends? Type the letter.
A. int i = 0; while (i < 5) { i++; }
B. int i = 1; while (i < 100) { i *= 2; }
C. int i = 10; while (i != 0) { i -= 3; }
D. int i = 5; while (i > 0) { i--; }

  

  
In C, i takes 10, 7, 4, 1, -2, … and skips 0, so i != 0 is always true. Testing with > or < instead of != avoids this trap.



  

  
What is k at the end?


int total = 0;
int k = 1;
while (total < 10)
{
    total += k;
    k++;
}

  

  
total grows 1, 3, 6, 10 while k goes 2, 3, 4, 5. When total reaches 10 the test fails, and k is already 5.








  
for loops

  
A for loop packs the start, the test, and the update into one header.

  
for (int i = 0; i < 5; i++)    // initialization; test; update
{
    System.out.print(i + " ");
}

  
Execution order: initialization (once) → test → body → update → test → body → update → … until the test is false. The update runs after the whole body.

  
    
    
  • The variable set up in the initialization is the loop control variable. If you declare it in the header (int i = 0), it exists only inside the loop.
    • 
    
  • Any for loop can be rewritten as an equivalent while loop, and the other way around.
    •

Count 1 up to nfor (int i = 1; i <= n; i++)n

    
Count down from n to 1for (int i = n; i > 0; i--)n

    
Every other valuefor (int i = 0; i < n; i += 2)about n / 2

Number algorithms

  
Selection and iteration combine into a small set of standard algorithms. Learn the pattern, then adapt it.

  
Divisibility

  
int n = 36;
int d = 6;
boolean divisible = (n % d == 0);   // true when d divides n evenly

  
n % d == 0 is true when d divides n evenly. n % 2 == 0 tests for even.

  
Digits of an integer

  
int num = 4072;
while (num > 0)
{
    int digit = num % 10;   // the last digit
    num = num / 10;         // removes the last digit
}

  
% 10 gives the last digit and / 10 removes it (integer division). Repeat while the number is greater than 0.

  
Counting, sum, and average

  
int sum = 0;
int count = 0;
for (int i = 1; i <= 10; i++)
{
    sum += i;               // accumulator
    count++;                // counter
}
double avg = (double) sum / count;

  
A counter adds 1 each time a criterion is met. An accumulator adds a value each pass. For an average, divide by the count, and make sure one operand is a double, or the division truncates.

  
Minimum or maximum

  
int max = 0;                  // start at or below the smallest value you expect
for (int i = 1; i <= 6; i++)
{
    int v = (i * 5) % 7;
    if (v > max)
    {
        max = v;              // remember the largest so far
    }
}

  
Start with a value that any real value will beat, then replace it whenever a better one comes along. (For a minimum, start with a very large value, or the first value.)

  

  
What is sum at the end?


int num = 4072;
int sum = 0;
while (num > 0)
{
    sum += num % 10;
    num /= 10;
}

  

  
The loop peels off the last digit each pass: 2, 7, 0, 4. Their sum is 13.



  

  
What is count at the end?


int count = 0;
for (int i = 1; i <= 30; i++)
{
    if (i % 4 == 0 || i % 6 == 0)
    {
        count++;
    }
}

  

  
Multiples of 4 up to 30: 7. Multiples of 6: 5. Multiples of both (12 and 24) are counted once by the ||: 7 + 5 - 2 = 10.



  

  
What is max at the end?

{

    if (v > max)
    {

    }
}

  

  
v takes the values 5, 3, 1, 6, 4, 2 as i goes from 1 to 6. The largest is 6.

{

}

sum is 10. The division 10 / 4 happens with two ints, so it is 2. That int is then stored as 2.0. Use sum / 4.0 to keep the decimal part.








  
String algorithms

  
To process a String, loop over its positions and look at one substring at a time. The char type is not part of this course, so you will use substring(i, i + 1) for a single letter.

  
Find out whether a letter has a property

  
String s = "banana";
boolean found = false;
for (int i = 0; i < s.length(); i++)
{
    if (s.substring(i, i + 1).equals("n"))
    {
        found = true;          // at least one letter has the property
    }
}

  
Start with found = false and switch it to true when a match appears. To ask whether every letter has a property, start with true and switch to false at the first letter that fails.

  
Count letters that meet a condition

  
String s = "banana";
int count = 0;
for (int i = 0; i < s.length(); i++)
{
    String letter = s.substring(i, i + 1);
    if (letter.equals("a"))
    {
        count++;
    }
}

  
Build a reversed string

  
String w = "java";
String reversed = "";
for (int i = 0; i < w.length(); i++)
{
    reversed = w.substring(i, i + 1) + reversed;   // the new letter goes in front
}

  
Look at several letters at a time

  
String s = "banana";
int count = 0;
for (int i = 0; i < s.length() - 1; i++)   // stop early so i + 2 still fits
{
    if (s.substring(i, i + 2).equals("an"))
    {
        count++;
    }
}

  
    
    
  • Valid indexes are 0 to length() - 1. A window of 2 letters needs i + 2 <= length(), so the loop test is i < s.length() - 1. Going past the end throws an exception.
    • 
    
  • Compare the letters with equals, not ==.
    • 
    
  • The trace table stepper has a “reverse a word” program you can run on any word.
    • 
  

  

  
What is c at the end?


String s = "banana";
int c = 0;
for (int i = 0; i < s.length(); i++)
{
    if (s.substring(i, i + 1).equals("a"))
    {

    }
}

  

  
The loop checks each one-letter substring of “banana.” The letter a appears at indexes 1, 3, and 5.

The two-letter windows of “banana” are ba, an, na, an, na. The window an appears twice. The loop stops at length() - 1 so the last window still fits.

Nested loops

  
When a loop is inside another loop, the inner loop must finish all of its passes before the outer loop moves to its next pass.

  
for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= row; col++)
    {
        System.out.print("*");
    }
    System.out.println();
}

  
    
    
  • If the inner loop always runs the same number of times, the body runs (outer passes) × (inner passes) times.
    • 
    
  • If the inner bound depends on the outer variable (like col <= row), add up the inner counts: 1 + 2 + 3 + …
    • 
    
  • Nested loops produce grids and triangles: the outer loop is usually the row, the inner loop is the column.
    • 
  

  

    
Nested loop grid

    
Each filled cell is one run of the body. The number is the order it ran. Rows are i and columns are j.

    

    

    

    

  

  

  
What prints? (separate lines with |)


for (int r = 1; r <= 3; r++)
{
    for (int c = 1; c <= r; c++)
    {
        System.out.print(c);
    }
    System.out.println();
}

  

  
The inner loop restarts for every row. Row 1 prints 1, row 2 prints 12, row 3 prints 123 (the print calls add no spaces). The println ends each row.



  

  
What prints? (separate lines with |)


for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        System.out.print(i * j + " ");
    }
    System.out.println();
}

  

  
For each i, the inner loop runs j from 1 to 3 and prints i * j. The inner loop finishes all its passes before i goes up.



  

  
What is count at the end?


int count = 0;
for (int i = 0; i < 4; i++)
{
    for (int j = 0; j < 5; j++)
    {
        count++;
    }
}

  

  
The outer loop runs 4 times. Each time, the inner loop runs 5 times. 4 × 5 = 20.



  

  
What is count at the end?


int count = 0;
for (int i = 0; i < 5; i++)
{
    for (int j = i + 1; j < 5; j++)
    {
        count++;
    }
}

  

  
The inner loop runs 4, 3, 2, 1, then 0 times: 4 + 3 + 2 + 1 + 0 = 10.








  
Counting executions

  
A statement execution count is the number of times a statement runs. You find it by tracing the loops, and it tells you how the amount of work grows.

  
    
    
  • One loop that runs n times: the body runs n times.
    • 
    
  • Two loops one after the other: the counts add.
    • 
    
  • Loops nested inside each other: the counts multiply (or add up row by row when the inner bound changes).
    • 
    
  • A loop that doubles its variable (i *= 2) runs far fewer times than n.
    • 
  

  

    
Execution counts

    
Change n and compare how each pattern grows when n doubles.

    

    

  

  

  
With n = 10, how many times does count++ run?


int n = 10;
int count = 0;
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < n; j++)
    {
        count++;
    }
}

  

  
The outer loop runs 10 times and the inner loop runs 10 times for each: 10 × 10 = 100.



  

  
Using the same code, if n doubles to 20, the count is multiplied by what number?

  

  
With n = 20 the count is 20 × 20 = 400, which is 4 times 100. Doubling n quadruples the work of a nested loop.



  

  
How many times does count++ run?


int count = 0;
for (int i = 1; i < 64; i *= 2)
{
    count++;
}

  

  
i takes 1, 2, 4, 8, 16, 32. Next is 64, which fails the test. Doubling loops run far fewer times than n.

Common FRQ mistakes

  

    
Students writeWhat really happens

    
while (num >= 0) in digitSumnum reaches 0 and the test stays true: an infinite loop.

    
sum = num % 10;Replaces the total on every pass. Use +=.

    
Forgetting num /= 10;The last digit never goes away, so the loop never ends.

    
left == right for StringsCompares references, not letters. Use left.equals(right).

    
return true; inside the palindrome loopOne matching pair does not prove the rest match. Return true only after the loop.

    
Looping to i <= word.length()The last pass asks for a letter that does not exist and throws an exception.

    
No println after the inner loopAll the stars end up on a single line.

  






  
Common traps

  

    
Students thinkWhat is true

    
= compares two values= assigns. == compares. For an int, if (x = 5) does not compile.

    
A semicolon after the condition is harmlessif (x > 3); (or a loop header followed by a semicolon) is an empty body. The braces after it always run.

    
Without braces, an if controls the whole indented blockOnly the single next statement belongs to it. Use braces every time.

    
Two separate ifs behave like an else if chainSeparate ifs can all run. In an else-if chain, at most one body runs.

    
An else pairs with the if it lines up withIt pairs with the nearest unmatched if, whatever the indentation shows.

    
!(a && b) is !a && !bDe Morgan: negate each part and switch the operator. It is !a || !b.

    
!(x < 5) is x > 5It is x >= 5. The boundary value stays included.

    
|| is checked before &&&& binds tighter: a || b && c means a || (b && c).

    
Put the guard on the right: x / y > 2 && y != 0Short-circuiting only protects the right side. Put the guard first: y != 0 && x / y > 2.

    
== compares Strings== compares references. Use s1.equals(s2) to compare the characters.

    
A while loop checks after each passIt checks before every pass, including the first, so it may run zero times.

    
A loop with != always endsi != 0 with i -= 3 from 10 skips 0 and never stops. Prefer <, >, <=, >=.

    
for (int i = 0; i <= 4; i++) runs 4 timesIt runs 5 times (0, 1, 2, 3, 4).

    
A for loop variable still exists after the loopOnly if it was declared before the loop. for (int i …) limits i to the loop.

    
sum / 4 keeps the decimalint ÷ int drops it. Use sum / 4.0 or (double) sum / 4.

    
A 2-letter window can loop to i < s.length()substring(i, i + 2) needs i + 2 ≤ length, so the test is i < s.length() - 1. Going further throws an exception.

    
The inner loop keeps its value between outer passesIt restarts every time. The body runs (outer passes) × (inner passes) times when the inner count is constant.

    
sum = num % 10 adds the digitPlain = replaces the total. Use sum += num % 10.
